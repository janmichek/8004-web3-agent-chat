web3Agent

Create AI agents with their own wallets on Arbitrum, Ethereum, or Mantle, register them on ERC-8004, and talk to them from a web console or CLI. Each agent can be reached over chat, MCP and A2A.

What an agent is

  • Wallet: its own private key, funded from a master wallet or your connected wallet.
  • Config: an ERC-8004-shaped file with endpoints, selected actions and tools, OASF domains and skills, and x402 support.
  • Chat memory: LangGraph checkpoints, one thread per agent.
  • On-chain identity: bound in the ERC-8004 Identity Registry, with the registration file pinned to IPFS.

Agent discovery: agent card (A2A). Experimental. Not for production or real funds.
